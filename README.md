# berkit

ASN.1 BER and DER in Rust, built clause by clause from ITU-T X.690 (02/2021) and X.680, with a language-neutral
conformance corpus in `corpus/`. `no_std`, no allocation, no dependencies. Nothing here is published.

`docs/design/` has the notes each module was built from. `ROADMAP.md` lists what is pinned by a test and the
policy decisions the standard leaves open.
